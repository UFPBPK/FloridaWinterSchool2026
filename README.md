# FloridaWinterSchool2026

I present two lectures in the Florida Winter School offered by the University of Florida Center for Pharmacometrics and Systems Pharmacology. On Day 1, I present a lecture entitled "A Machine Learning-Enabled PBPK Model for Nanoparticles". On Day 3, I present a lecture entitled "Sensitivity, Uncertainty, and Variability Analyses". This repository contains supplementary code and data files for these two lectures. Attendees can download these files and reproduce the results based on the instructions on the slides.
